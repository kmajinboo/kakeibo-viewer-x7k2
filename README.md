# 家計集計ビューア

家計計画表（Excel）を読み込み、月別の収入・支出・繰越を表とグラフで表示するページです。
Excelの読み取りと集計は、すべて利用者のブラウザの中で行います。ファイルはGitHubや外部には送信されません。

## 使い方

1. 公開されたページを開く
2. 「家計表（xlsx）を読み込む」を押して、家計計画表のExcelファイルを選ぶ（ドラッグでも可）
3. 表とグラフが表示される。月のシートを増やしたファイルを読み込むと、再集計される
4. 区分の分け方は、ページ下部の「区分の設定」で変更できる（ブラウザに自動保存）
5. 様式が違うExcelは、「読み取りルール（様式定義）」から様式定義ファイル（JSON）を読み込んで対応する（詳しくは `SPEC.md`）

## GitHub Pagesで公開する手順

画面の表記は変更されることがあります。

1. GitHubにログインし、右上の「＋」→「New repository」を選ぶ
2. Repository nameを決める（推測されにくい名前を推奨。例：`kakeibo-viewer-x7k2`）
3. 公開設定は「Public」を選び、「Create repository」を押す
4. 「uploading an existing file」を選び、`index.html`、`README.md`、`SPEC.md`、`format-standard.json`、`家計計画表_標準様式.xlsx` の5つをドラッグして「Commit changes」を押す（更新のときは、同じ名前のファイルを上書きする）
5. 「Settings」→「Pages」を開く
6. 「Build and deployment」の「Source」を「Deploy from a branch」、Branchを「main」「/ (root)」にして「Save」を押す
7. 数分後に、`https://（GitHubのユーザー名）.github.io/（リポジトリ名）/` で開けるようになる
8. このURLを、使う人にだけ伝える

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ページ本体（標準様式の読み取りルールを内蔵） |
| `format-standard.json` | 標準様式の定義（解説付き）。自分で様式定義を書くときの雛形 |
| `SPEC.md` | 仕様書（読み取りの流れ、様式定義の書き方、制約） |
| `README.md` | この説明 |
| `家計計画表_標準様式.xlsx` | 配布用のひな形。各事業所はこれをダウンロードして入力する（個人情報・金額は含まない） |

## 注意

- 公開リポジトリのページは、URLを知っていれば誰でも開けます。パスワードなどのアクセス制限はありません。このページには検索エンジンに載せないための指定（noindex）を入れていますが、これはアクセス制限ではありません。
- 非公開（Private）のリポジトリでページを公開するには、GitHubの有料プランが必要です。
- **家計表のExcelファイルや、氏名などの個人情報を、リポジトリにアップロードしないでください。** Excelファイルはページ上で読み込んで使います。
- このページには、家計の金額データは含まれていません。
- 区分の設定は、使うブラウザごとに保存されます。別のパソコンで同じ設定を使うには、「設定をファイルに保存」したファイルを、そちらで「設定ファイルを読み込む」から読み込んでください。
- 何も指定しない場合は、標準様式（家計計画表：E列に費目名、F列に金額、収入はA・B列とC列、G1セルに「2026年1月）」の形式で月）で読み取ります。様式が違う場合は、様式定義ファイルを書いて読み込んでください（`SPEC.md` 参照）。
- 月ごとのシートに項目が縦に並ぶ形式のみ対応しています。月が横に並ぶ表や、日付・費目・金額が縦に並ぶ一覧表には、今は対応していません。
